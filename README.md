# Netfuse

Netfuse is an experimental macOS project to combine independent Internet connections, including routes contributed by iPhone and iPad web pages through a relay.

This public repository is the **release channel**. There is no downloadable Netfuse application yet. Verified builds, release notes, supported-device information, and checksums will appear under [Releases](https://github.com/ChargedAA/netfuse/releases) when the application is ready. Development source, test harnesses, and device-specific research are kept separately in a private development repository.

The current experiments have proved that Safari can load a Mac-hosted page over a direct iPhone USB connection while Wi-Fi is on. They have **not** yet proved an independent iPhone Wi-Fi path to a remote relay, system-wide traffic bonding, reliable background contribution, or performance alongside a busy game server. No release will claim those capabilities before measurement.

This repository contains no binaries, installer, or signed app at present. Do not treat its existence as a working VPN or network accelerator.
